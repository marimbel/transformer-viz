01 · Data pipeline

From text to numbers

A model can't read letters. Training text is split into tokens (here, single characters), each token gets an integer ID, and each ID looks up a learned vector called an embedding. The training task is simple: given the tokens so far, predict the next one.

Training corpus

03 · Self-attention

How tokens connect to each other

Attention is how information moves between positions. Each token makes a query ("what am I looking for?"), a key ("what do I contain?") and a value ("what I'll pass along"). The score between two tokens is q·k / √d_head; a softmax turns each row of scores into weights that add up to 1. Because the model predicts the future, a token may only look at itself and earlier tokens (the causal mask). Untrained, the weights are near-uniform; after training, heads specialize.

04 · Neurons & connections

Inside the MLP: nodes and weights

After attention mixes information across positions, each position goes through a small neural network on its own: expand from d_model to d_ff neurons, apply ReLU (negative values become 0), and project back. Each circle is a neuron holding one number for the selected token. Each line is a weight, one learnable parameter. Training adjusts those lines.

05 · Training

The training loop

Training repeats five steps thousands of times. Use Step through to walk one iteration phase by phase, or Train to run continuously and watch the loss fall. The loss is cross-entropy: the negative log of the probability the model gave the correct next character. Guessing uniformly at random scores ln(vocab size).

1
Sample a batch
Cut random windows from the corpus: inputs and shifted targets.
2
Forward pass
Run inputs through every layer to get a score for each possible next token.
3
Compute loss
Softmax the scores; loss = −log p(correct token), averaged.
4
Backward pass
Backpropagation: the chain rule gives ∂loss/∂w for every weight.
5
Update weights
Adam nudges every weight against its gradient, scaled by the learning rate.

06 · Scale

From this toy to a large language model

Large models use the same blocks; they're just wider, deeper and trained on far more tokens. Nearly all parameters live in the attention and MLP matrices, which grow with d_model². Pick a preset or drag the sliders.

Built from scratch in plain JavaScript: a small matrix autograd engine, a GPT-style model (pre-LayerNorm, causal multi-head attention, ReLU MLP) and the Adam optimizer with gradient clipping. No ML libraries, no server: everything above runs and trains in this tab.

Simplifications vs. production LLMs: character tokens instead of subword (BPE) tokens, ReLU instead of GELU, no dropout, tiny size, single-example batches processed sequentially.
